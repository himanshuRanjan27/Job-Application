JobApp - Spring Boot Application
A lightweight, MVC-based web application built with Spring Boot to manage job postings. This application allows users to view available jobs and submit new job openings through an interactive web interface.

🚀 Features
View All Jobs: Dynamically lists available job postings with details like required experience and tech stack.

Add Job Postings: A dedicated form to submit new job listings seamlessly.

Spring MVC Architecture: Clean separation of concerns using Model-View-Controller design patterns.

In-Memory Storage: Quick, hassle-free data handling using an array-list-based mock repository.

🛠️ Tech Stack
Backend: Java 17+, Spring Boot (v3.x)

Web Layer: Spring MVC, Thymeleaf / JSP (for rendering views)

Utilities: Lombok (for boilerplate-free boilerplate models)

Build Tool: Maven
